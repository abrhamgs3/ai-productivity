# Non-Overlap Matrix: Root vs Advanced Manuscripts

| Dimension | Root Paper (`paper/`) | Advanced Paper (`advanced_research_manuscript/`) |
|---|---|---|
| Main objective | Policy-facing baseline evidence | Diagnostics-heavy credibility assessment |
| Primary novelty | Reproducible applied baseline + practical robustness | Full identification/inference stress-testing architecture |
| Core estimators | FE, TWFE, trimmed, lagged, clustering variants, placebo outcome | FE/TWFE + event-style leads, placebo leads, dynamic FD-IV, influence diagnostics |
| Multiple testing control | Not central contribution claim | Explicit BH-FDR interaction-family correction |
| Influence diagnostics | Optional brief mention only | Formal leave-one-out + top-GDP exclusions + figure/table |
| Magnitude translation | Short policy interpretation | Full table with SD/IQR shock mapping and CIs |
| Assumptions mapping | Narrative assumptions section | Assumptions-to-tests matrix + checklists |
| Annex intensity | Moderate | High (full technical diagnostics archive) |
| Target audience | Applied policy/evidence readers | Methods-sensitive referees and technical empirical readers |
| Claim boundary | Robust association with practical implications | Diagnostically robust regularity with explicit non-identification boundary |

## Editorial Rule
- Shared baseline results are acceptable.
- Contribution framing, diagnostic depth, and novelty statements must remain differentiated.
