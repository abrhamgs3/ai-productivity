# AI and Productivity

Panel econometrics research pipeline studying the relationship between AI adoption
and Total Factor Productivity (TFP) across 193 countries, 2010–2024.

---

## Quick start

### 1. Install

```bash
git clone https://github.com/<your-username>/ai-productivity.git
cd ai-productivity
uv venv
uv pip install -e ".[dev]"
```

### 2. Add your data

Place the following files in the indicated directories (see `scripts/` for
download helpers):

```
data/raw/wdi.csv               World Development Indicators
data/raw/pwt.csv               Penn World Tables 10.x
data/raw/ai_proxy.csv          AI adoption proxy
data/processed/panel_clean.csv ← generated by scripts/02_clean_data.py
```

### 3. Check your environment

```bash
ai-productivity doctor
```

All checks should show ✔ before running the pipeline.

### 4. Run the pipeline

```bash
ai-productivity run
```

This executes in order:

1. **Validate** — checks required columns, duplicates, missing values
2. **Load** — drops aggregate/non-sovereign entities
3. **Econometrics** — robustness, sensitivity, falsification, and heterogeneity suites
4. **Tables** — CSV + LaTeX summaries in `tables/`
5. **Figures** — PDF + PNG publication figures in `figures/`
6. **Narratives** — LaTeX results sections in `paper/sections/`

## CLI reference

```
Usage: ai-productivity [OPTIONS] COMMAND [ARGS]...

  AI and Productivity — panel econometrics research pipeline.

Options:
  -V, --version  Show version and exit.
  --help         Show this message and exit.

Commands:
  doctor  Verify that the environment is ready to run the pipeline.
  run     Run the full analysis pipeline.
```

### `ai-productivity run` options

| Option | Default | Description |
|---|---|---|
| `--data-path` | `data/processed/panel_clean.csv` | Input panel CSV |
| `--tables-dir` | `tables/` | Output directory for tables |
| `--figures-dir` | `figures/` | Output directory for figures |
| `--paper-dir` | `paper/sections/` | Output directory for LaTeX narratives |
| `--verbose / -v` | off | Enable DEBUG-level logging |
